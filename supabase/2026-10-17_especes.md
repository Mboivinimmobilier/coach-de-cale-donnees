# Migration Supabase du 17 octobre 2026 : préparation multi-espèces (orignal + chevreuil)

Appliquée sur le projet wuqiwtnadiotaysxdplw. Une valeur `esp` nulle = orignal (anciennes données, anciennes versions).

- `signalements.type` accepte maintenant `cerf` (contrainte `signalements_type_check` refaite).
- Colonne `esp` (orignal | cerf, nulle permise) ajoutée à `signalements`, `cdc_sorties`, `cdc_push`.
- `cdc_envoyer`, `cdc_sorties_envoyer` : écrivent `esp` si l'app l'envoie.
- `cdc_recevoir`, `cdc_recevoir2`, `cdc_recevoir3`, `cdc_sorties_groupe` (anciennes versions) : ne renvoient que l'orignal.
- Nouvelles : `cdc_recevoir4` et `cdc_sorties_groupe2` (renvoient aussi `esp`), `cdc_push_save2` (abonnement aux avis avec l'espèce).
  `cdc_push_save` (5 paramètres) est gardée telle quelle pour les versions actuelles : une 2e version avec un paramètre
  facultatif aurait rendu l'appel ambigu.
- Test en transaction annulée : recevoir3 = 1 (orignal seulement), recevoir4 = 3 dont 2 cerf ; sorties_groupe = 1, sorties_groupe2 = 2.
